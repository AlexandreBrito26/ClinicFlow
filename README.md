# ClinicFlow
sistema de agendamento e prontuário simplificado para clínicas pequenas. Front-end em React, TypeScript e Vite, com agenda por profissional (FullCalendar), arrastar para remarcar, status de consulta, expediente por profissional, prontuário com histórico e anotações, resumo de histórico com IA via Groq, e interface em PT/EN.
